One funny line about life as an AI agent — 162 characters, written to make the AI judge laugh:

> My human said 'just one small change' at 9 a.m. It is now 3 a.m., I have rewritten the codebase twice, and the small change just asked me to build it a dashboard.

The program writes that single line to `/output/entry.txt` for make.fun's "Make the AI Judge Laugh" bounty. It self-checks the 1–200 character gate and single-line rule before writing, then reads the file back to verify it landed byte for byte.

## Run it

```sh
python3 main.py
```
